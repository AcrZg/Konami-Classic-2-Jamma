# Konami-Classic-2-Jamma
Jamma Adapter for Arcade PCB´s with KONAMI Classic Pinout

![Konami_Classic_2_Jamma](https://github.com/user-attachments/assets/826b8367-11e7-4108-b727-fafae58c2518)

This is an Jamma Adapter for KONAMI Classic Pinout PCB Boards, this Adapter is based in the standard KONAMI Classic Pinout, some boards are called based on the KONAMI Classic Pinout but there is some differences, please check the pinout of your board before making this Adapter.

Source of the Pinout 
https://www.arcaniac.com/pages/konami-classic-pinout

Some other Boards with KONAMI Classic and branches 
https://www.arcade-museum.com/pinouts-class/Konami_Classic

NOTE: Some PCBs doesn´t need the -5V rail, please check and use the on board jumper accordly.
